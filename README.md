# Face-CV-Agent

This repository contains a Face Computer Vision Agent designed to accept a defined image input.

This requires the OPENCV package. instal using (pip install opencv-contrib-python).
Make sure that your palm images are in the same folder as the project.
Open terminal and CD to the directory where the Python file is.
Paste a command with different file-names/files to test different cases:

python3 "Face agent.py" FaceTest.PNG

That is it!
